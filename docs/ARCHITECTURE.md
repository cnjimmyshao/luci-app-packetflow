# Architecture

Packet Flow is a read-only LuCI inspector for the *effective* Linux/OpenWrt networking state.

## Data sources

- `nft -j list ruleset`: Netfilter base chains, hooks and priorities.
- `ip -j rule show`: RPDB policy rules and priorities.
- `ip -j route show table all`: all kernel routing tables.
- `ip -j link show`: egress/ingress interfaces.

The UI deliberately reads live kernel state rather than only UCI configuration. This allows it to observe rules generated by fw4, pbr, mwan3, VPN packages and other software.

## Pipeline model

```text
Ingress
  -> Netfilter hook/base-chain priority
  -> packet classification / marks
  -> RPDB (ip rule)
  -> routing table
  -> egress interface
```

This is a model, not a claim that every packet traverses every displayed stage. Locally generated traffic, bridging, flow offload, XDP/tc, policy routing and tunnelling can change the path.

## Safety model

v0.x is intentionally read-only. It must not mutate nftables, ip rules, routes or interfaces.

## Roadmap

1. Live-state inventory (MVP)
2. Relationship graph between marks, rules, tables and interfaces
3. Conflict detection (duplicate marks, missing tables/default routes, suspicious priorities)
4. Packet trace using kernel-supported tracing where safe
5. Optional advanced editing only after the inspector is mature
